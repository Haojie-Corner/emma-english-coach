# AI English Teacher QA Checklist

这份清单用于每次发布前快速验证核心学习体验。

## 1. 账号和同步

- 新账号可以注册、登录、退出、重新登录。
- 手机和电脑使用同一账号时，学习目标、弱点档案、Emma 最近消息、今日复盘能同步。
- 如果 Supabase 没有运行最新 `supabase-setup.sql`，页面会提示同步需要检查，而不是静默失败。

## 2. 今日学习闭环

- 首页能看到今日计划、今日学习闭环、今日复盘闭环。
- 完成打卡、学习分钟、课程或练习后，首页状态会更新。
- 今日复盘能说清楚：今天完成了什么、下次只盯哪个弱点、明天建议做什么。

## 3. Emma 老师

- Emma 在首页、课程、练习中心、词汇本、个人页都能识别当前场景。
- 当同类弱点重复出现时，Emma 悬浮按钮出现提醒点。
- 点击“让 Emma 带我练”后，Emma 会基于弱点给出 5 分钟定向练习。

## 4. 练习中心

- 自由录音可以录音、停止、分析、重练。
- 语法纠错能保存错误类型到个人页。
- 雅思 Part 1、Part 2、Part 3 能录音并返回 Band 反馈。
- 听写、听力、随拍、编程英语失败时有可理解的错误提示。

## 5. 词汇本

- 可以手动添加单词，AI 填写失败时仍可手动保存。
- 今日复习能翻卡、评分、更新熟悉度。
- 词汇空状态、搜索无结果、今日无复习都有下一步入口。

## 6. 移动端体验

- iPhone/Android 宽度下没有横向滚动。
- 底部导航、Emma 悬浮按钮、弹窗不会互相遮挡。
- 点击目标至少 36px 高，常用主按钮至少 42px 高。
- 添加到手机桌面的提示不会反复打扰用户。

## 7. 发布前命令

```bash
npm run lint
npm run qa
npm run build
```
